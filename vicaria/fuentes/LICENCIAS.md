# Licencias de las fuentes de los rótulos

Fuentes agregadas para la tipografía de los rótulos (`rotulos.tipografia`). Se copió solo el archivo latino de un peso de cada paquete (700, salvo Nunito 800 y Oswald 600), sin ejecutar nada del paquete.

| Archivo | Fuente | Paquete npm (versión exacta) | Licencia |
|---|---|---|---|
| `lora-latin-700-normal.woff2` | Lora | `@fontsource/lora@5.3.0` | SIL Open Font License 1.1 (`OFL-1.1`) |
| `source-sans-3-latin-700-normal.woff2` | Source Sans 3 | `@fontsource/source-sans-3@5.3.1` | SIL Open Font License 1.1 (`OFL-1.1`) |
| `cinzel-latin-700-normal.woff2` | Cinzel | `@fontsource/cinzel@5.3.0` | SIL Open Font License 1.1 (`OFL-1.1`) |
| `playfair-display-latin-700-normal.woff2` | Playfair Display | `@fontsource/playfair-display@5.3.0` | SIL Open Font License 1.1 (`OFL-1.1`) |
| `eb-garamond-latin-700-normal.woff2` | EB Garamond | `@fontsource/eb-garamond@5.3.0` | SIL Open Font License 1.1 (`OFL-1.1`) |
| `merriweather-latin-700-normal.woff2` | Merriweather | `@fontsource/merriweather@5.3.0` | SIL Open Font License 1.1 (`OFL-1.1`) |
